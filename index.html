APPLICATION 01 · HARDWARE UTILITYThermalright Mini Display
NATIVE C++ · v3.0.8
REAL APPLICATION SCREENSHOTBA120 Vision · 240 × 320 panel
A LIGHTWEIGHT COMPANION FOR YOUR COOLER LCD

Your cooler screen.
Make it yours.

A focused native Windows utility for the Thermalright Burst Assassin 120 Vision USB LCD. Choose a favourite image or animated GIF, adjust its fit and orientation, preview it, then send it directly to the cooler over USB HID.

Download for Windows ↗ View source on GitHub ↗
~8.7 MBRAM observed in one Task Manager test
0.0%Static-image CPU sample observed on one test PC
0.4–0.6%GIF CPU sample observed during playback
Native C++Win32 app; no .NET runtime dependency

Why was it created?

Many cooler-control suites bundle a broad set of monitoring and tuning features. This project takes a narrower approach: it exists to put the image or animation you choose on the BA120 Vision LCD, without running an unrelated monitoring dashboard, overlays, fan curves or a large control centre. A small, single-purpose program can be easier to launch, understand and leave running in the background.

What you can do

  • Load a still image or animated GIF.
  • Preview the logical 320 × 240 canvas before sending it.
  • Choose image scaling such as Fill / crop and adjust rotation.
  • Set a maximum GIF frame rate.
  • Connect, refresh and disconnect the detected BA120 Vision HID device.
  • Minimise to the system tray and optionally start with Windows.

Where this app wins: Its deliberately small scope, native executable and low observed resource footprint. Where TRCC wins: It is the official BA120-compatible option and offers richer display customisation plus CPU/GPU information. Choose TRCC when you need live telemetry; choose Mini Display when you want a straightforward image/GIF player and prefer a focused utility.
Performance note: The repository reports approximately 8.7 MB memory use, a 0.0% static-image CPU sample and 0.4–0.6% while playing GIFs in one user test. These are observations from one machine and measurement window, not guarantees. No matched benchmark against TRCC or AIDA64 has been performed, so this page does not claim a measured resource advantage over them.

Compatibility: The current implementation targets the Thermalright Burst Assassin 120 Vision (BA120 Vision) profile, USB VID 0416 / PID 5302.
