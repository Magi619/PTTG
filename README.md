# Maksoft

A unified workspace for practical browser-based tools.

## Project status

Maksoft is being rebuilt as a fresh, Apple-inspired tools platform. The original `uknowwhoim` repository remains unchanged.

## Local preview

Open `index.html` in a modern browser. The tools run as standalone pages under `tools/`.

## Structure

- `index.html` — Maksoft dashboard
- `assets/` — shared styles and scripts
- `tools/` — individual browser tools
