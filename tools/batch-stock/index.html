Batch Stock Lookup — How to Use

Check multiple product codes in one run, review stock quantities and vintage changes, and export the results. Vintage controls cover the current year, the previous five years and the next five years, with manual vintage entry also available.

Run a stock check

  • Paste product codes into the input box, one code per line.
  • Choose the required stock threshold or keep the default setting.
  • Select Fetch Stock Info to process the pasted product codes.

Review and export

  • Review the Valid Stock Quantity, Vintage Changed, Invalid / Remarks and other result sections.
  • Select Auto Vintage Checker once to test the current year, the previous five years and the next five years for every remaining invalid product. The tool stops checking an item when it finds a usable vintage.
  • To check another vintage, enter a four-digit year (for example 2026) or a two-digit vintage (for example 26) in Manual Vintage, then select Check Vintage. You can also press Enter.
  • Use Default Vintage to restore the original product-code list and run the standard stock check again.
  • Use Clear Cache when you need to remove cached lookup data, and Export to Excel to save the results.
