Why we created it

A small display should be yours to customise.

The aim is to make the BA120 Vision easier to use with personal artwork, animated GIFs and custom layouts. Instead of being limited to one fixed screen, you can prepare the visual you want, preview it, adjust its fit and orientation, then send it to the display.

🎨

Your own look

Use wallpapers, artwork, logos, avatar screens, GIF animations or your own designed status panel.

🪶

Focused native utility

A dedicated C++ app for display control rather than a full desktop monitoring suite. A lightweight design is the goal; no independent CPU benchmark is claimed here.

🛠️

Practical controls

Device refresh, connection controls, scaling, rotation, playback start/stop and startup-to-tray options.

CPU · RAM · GPU · more

What about system monitoring?

A mini LCD is a great place for quick system information. The important distinction is whether those numbers are live sensor readings or simply part of an image.

CPUUsage, temperature, clock speed and power
MemoryRAM usage, used / available capacity
GPUGPU load, temperature, clock and power
VRAMDedicated video memory usage
CoolingFan RPM and pump speed
NetworkUpload and download rates
Current-build accuracy: The repository also contains sensor/telemetry-related components. The page calls out CPU, memory and GPU readings as supported where the build exposes them; exact sensors depend on the current implementation and hardware. This page does not label those readings as live features unless the repository implementation confirms them.
How it compares

Different tools solve different jobs.

The Mini Display utility is intended to control this particular HID display. Sensor tools are better suited to collecting live readings; they are complementary rather than direct replacements.

Tool typeBest atStrengthTrade-off
Thermalright Mini DisplayBA120 Vision visual playbackDevice-focused controls, image/GIF loading, preview, scale and rotate optionsLive sensor telemetry is not shown in the current UI unless added by a future sensor integration
HWiNFO / hardware monitorsLive hardware sensor readingsCPU, RAM, GPU, temperatures, clocks, power and fan data depending on hardwareSensor collection alone does not provide this app's BA120-specific image/GIF playback controls
AIDA64 / RTSS-style dashboardsCustom performance overlays and sensor panelsRich layouts and live telemetry when configured with supported sensors and display pathsMore configuration; direct support for a particular USB HID LCD depends on integrations
Vendor display utilitiesManufacturer-supported device functionsOften convenient for supported devices and bundled presetsCustomisation and compatibility vary by device and software version
